# 나만의 프롬프트 관리 프로그램 ⭐

자주 쓰는 AI 프롬프트를 한곳에서 모아 보고, 찾아 쓰는 파이썬 콘솔 프로그램입니다.

## 프로그램 소개

생성형 AI를 쓰다 보면 잘 나온 프롬프트가 채팅 창이나 메모장에 흩어지기 쉽습니다. 나중에 다시 쓰려면 제목도, 용도도 기억나지 않는 경우가 많습니다.

이 프로그램은 프롬프트를 제목·내용·카테고리로 저장하고, 검색·상세 보기·즐겨찾기로 바로 꺼내 볼 수 있게 만들었습니다. 별도 설치 없이 터미널에서 `main.py`만 실행하면 됩니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록합니다. |
| 목록 보기 | 저장된 프롬프트를 번호, 카테고리, 제목, 즐겨찾기(⭐)와 함께 보여 줍니다. |
| 카테고리별 조회 | 카테고리 번호를 고르면 해당 분류의 프롬프트만 보여 줍니다. |
| 검색 | 제목 또는 내용에 검색어가 포함된 프롬프트를 찾습니다. |
| 상세 보기 | 번호를 입력하면 제목, 카테고리, 즐겨찾기, 내용 전체를 보여 줍니다. |
| 즐겨찾기 관리 | 번호를 골라 즐겨찾기를 추가하거나 해제합니다. |
| 즐겨찾기 목록 | 즐겨찾기로 표시된 프롬프트만 모아 보여 줍니다. |

> 추가·수정한 내용은 프로그램이 켜져 있는 동안만 유지됩니다. 종료하면 처음 등록된 기본 데이터로 돌아갑니다.

## 등록된 카테고리

프롬프트를 추가할 때 아래 목록에서 번호를 고르거나, 이름을 직접 입력할 수 있습니다.

| 카테고리 | 설명 |
| --- | --- |
| 텍스트 생성 | 글 작성, 요약, 번역처럼 텍스트를 만드는 프롬프트 |
| 이미지 생성 | 이미지 생성 AI에 넣을 설명·프롬프트 |
| 영상 생성 | 영상·숏폼 제작에 쓰는 프롬프트 |
| 페르소나 | AI의 역할이나 말투를 정하는 프롬프트 |
| 자동화 | 반복 작업이나 워크플로에 쓰는 프롬프트 |
| 기타 | 위 분류에 넣기 어려운 프롬프트 |

## 실행 방법 🚀

### 요구 사항

- Python 3.10 이상
- 외부 패키지 설치 없음 (표준 라이브러리만 사용)

### 실행 명령어

프로젝트 폴더에서 아래 명령을 실행합니다.

```bash
python main.py
```

## 사용 예시

프로그램을 실행하면 아래와 같은 메뉴가 반복해서 나타납니다. 번호를 입력한 뒤 `Enter`를 누르면 해당 기능이 실행됩니다.

```text
=== 나만의 프롬프트 관리 ===
1. 프롬프트 추가
2. 프롬프트 목록
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
7. 즐겨찾기 목록
0. 종료
선택:
```

목록은 예를 들어 이렇게 보입니다.

```text
1. [텍스트 생성] 블로그 글 작성 도우미 ⭐
2. [이미지 생성] 이미지 프롬프트 다듬기
3. [페르소나] 파이썬 튜터 페르소나 ⭐
```

## 프로젝트 구조

콘솔 프로그램이라 핵심 코드는 `main.py` 하나에 모여 있습니다.

```text
codysseyA1/
├── main.py      # 메뉴, 데이터, 기능 함수
└── README.md    # 프로젝트 설명
```

- `CATEGORIES`: 선택할 수 있는 카테고리 목록
- `prompts`: 프롬프트를 담는 리스트 (각 항목은 `title`, `content`, `category`, `favorite` 딕셔너리)
- `show_menu()`, `add_prompt()`, `show_list()` 등: 메뉴와 기능별 함수
- `main()`: 입력을 받아 해당 함수를 호출하는 반복 루프

## 기술 스택 / 특징

- **언어**: Python 3.10 이상
- **의존성**: 없음. `input()`, `print()`, 리스트·딕셔너리 등 기본 문법만 사용합니다.
- **구조**: 기능을 한 함수에 몰아넣지 않고, 추가·조회·검색·즐겨찾기처럼 역할별로 함수를 나눴습니다.
- **데이터**: 파일이나 데이터베이스 없이 메모리의 리스트에 저장합니다.
